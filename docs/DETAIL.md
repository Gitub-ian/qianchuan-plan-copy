# 千川计划复制 · 插件详情

## 它做什么

安装本插件后，DSH 的会话技能列表里会多出一个 `qianchuan-plan-copy` 技能。当你说「复制这条计划 <计划ID>」时，AI 会加载它并按固定流程执行：

1. 进入乘方 → 推商品 → 商品自选 → 用计划 ID 搜索，**确认只剩一条**
2. 打开计划详情抽屉，抓出全部参数（商品 ID、抖音号列表、ROI、预算、投放设置、素材数）
3. 把参数表 + **单条计划列表页截图**发给你，等你回「确认删除」
4. 删除原计划（释放「商品×抖音号」组合）
5. 在同一账户里按参数重建计划（计划名日期改当天）
6. 逐个抖音号全选其主页视频，核对素材总数
7. 归档参数与记录（Markdown），汇报新旧计划 ID 对照

## 为什么必须删除再建

乘方计划由「商品 × 抖音号」唯一确定，同一组合全店只能存在一条，平台也没有复制按钮。所以要复制，只能记录参数 → 删除原计划 → 用同组合重建。

## 技能里固化了什么

- 六阶段完整命令片段（可直接复制执行），基于 CDP 驱动 Edge
- 21 条铁律：坐标换算（截图 ÷ dpr）、哪些操作用 JS click 哪些必须真实点击、删除后等 ≥60 秒、已删除的抖音号不要选、计划名日期改当天……
- 10 条故障速查：搜索回车无效、抽屉卡加载中、发布按钮点空、素材卡片点了没选中、商品抽屉一直 0 条……
- 3 个经过实战修 bug 的脚本

## 安全与风险

删除不可恢复。技能正文把「搜索唯一性自查 + 用户明确确认」列为强制步骤，且规定确认截图必须是单条计划列表页而不是删除弹窗截图。插件本身只读取技能正文并注册，不访问网络、不写账户数据。

## 已知限制

- 只针对 Windows + Edge + CDP，其他浏览器需自行改脚本
- 技能正文里的坐标是在 1528×732 / dpr 1.25（也曾出现 dpr 2）环境下实测的，换显示器要重新量 dpr
- 账户 ID 默认写死一个，多账户需改技能正文或用不同 profile
