> 适用账户：【市场部短视频挂车】PX-奢思雅官方旗舰店-02 　千川 ID：**1860422794525708**
> 目标页面：巨量千川 → 乘方 → 推商品 → **自选商品**
> 本手册由实际执行 10+ 条计划复制沉淀，包含**全部已知坑与正确打法**。其他 AI / 其他会话拿到本文件即可独立完成一条计划的复制。

## 0. 先理解业务：为什么"复制"= 删除 + 重建

乘方计划有一条平台硬规则：

> **一条计划由「商品 × 抖音号」唯一确定。同一商品与同一抖音号，在全店只能存在一条乘方计划。**

因此平台上**没有「复制计划」按钮**，同组合也无法并存两条。所谓复制，只能：

1. 记录原计划的**全部参数**
2. **删除**原计划（释放「商品×抖音号」这个组合）
3. 用同样的商品、同样的抖音号、同样的预算/ROI **新建**一条
4. 把素材重新挂上去（逐号全选抖音主页素材）
5. 核对

**风险点全在"删错"和"建错"**：删除不可恢复，所以删除前必须有搜索唯一性自查 + 用户确认；建错则白删。

支持的命令：

| cmd | 参数 | 用途 |
|---|---|---|
| `eval` | `expr` | 执行 JS，返回最后表达式的值（最常用） |
| `shot` | `path` | 截图（已内置 bringToFront，窗口非前台也能截） |
| `clickAt` | `x`,`y` | **真实鼠标点击**（CSS 像素） |
| `clickText` | `text`,`exact`,`index`,`scope` | 按可见文字找元素并真实点击其中心 |
| `findText` | `text`,`exact` | 只查找，返回所有匹配的位置 |
| `setInput` | `sel`,`text` | 写输入框并派发 input 事件（**不保证触发搜索**） |
| `insertText` | `text` | 向当前焦点插入文字 |
| `key` | `key` | 发送真实按键（`Enter` 等，走 rawKeyDown+keyUp） |
| `type` | `text` | 逐字输入 |
| `nav` / `reload` | `url` / `wait` | 跳转 / 刷新 |
| `scroll` | `y` | `window.scrollBy` |
| `text` | — | 取页面 innerText |
| `tabs` / `inputs` / `frames` | — | 目标页列表 / 输入框清单 / frame 列表 |

**铁律**：页面里能 `JS .click()` 生效的控件，一律优先 JS click；只有「素材卡片」这类 React 合成事件不认的元素才用真实鼠标点击。

### A4 搜索（**强制步骤，防删错**）

**列表页真正的搜索框是** `input[placeholder*="回车搜索"]`（占位「输入计划名称/ID后回车搜索」）。
**不是** 占位含「计划名称」的那个——那是「更多筛选」面板里的 searchData 选择框，搜了不生效。

```js
(()=>{const i=document.querySelector('input[placeholder*="回车搜索"]');i.focus();
const s=Object.getOwnPropertyDescriptor(window.HTMLInputElement.prototype,'value').set;
s.call(i,'');i.dispatchEvent(new Event('input',{bubbles:true}));
s.call(i,'<计划ID>');i.dispatchEvent(new Event('input',{bubbles:true}));
i.focus();return i.value})()
```
然后 `{"cmd":"key","key":"Enter"}`，等 5 秒。

判定：

```js
(()=>{const t=document.body.innerText.replace(/\s+/g,' ');
return {count:(t.match(/共(\d+)条计划/)||[])[1],
        rows:[...document.querySelectorAll('tr')].filter(r=>/ID：/.test(r.innerText)).map(r=>r.innerText.slice(0,80))}})()
```

**必须 `count === "1"`**，否则停下来查原因，不允许继续。

## 4. 阶段 B：抓取原计划参数

### B1 打开详情抽屉

**点计划名**（右侧弹出抽屉），不要手工改 URL 加 `&adId=`（会整页卡死，只能关标签重来）。

```js
// 1. 先把行滚到视口中间
(()=>{const tr=[...document.querySelectorAll('tr')].find(r=>r.innerText.includes('<计划ID>'));tr.scrollIntoView({block:'center'});return 'OK'})()
// 2. 取计划名 span 的中心坐标
(()=>{const sp=[...document.querySelectorAll('span')].find(e=>e.innerText.trim()==='<计划名>');const r=sp.getBoundingClientRect();return {x:Math.round(r.x+r.width/2),y:Math.round(r.y+r.height/2)}})()
```
拿到坐标后 `clickAt`。

**成功判据**：URL 出现 `adId=<计划ID>`，且页面出现 tab「数据」。

> **抽屉卡「加载中」**：URL 已经有 adId，但 tab 一直不渲染、右侧空白。不要等，直接 `nav` 回列表 URL → 重新搜索 → 再点计划名，通常一次就正常。

### B2 抽屉的 8 个 tab

| tab | CSS 坐标 | 用途 |
|---|---|---|
| 数据 | (252,108) | 不用 |
| 商品 | (316,108) | 读商品 ID |
| 抖音号 | (380,108) | 读抖音号清单 |
| 素材 | (460,108) | 读素材数 / 添加视频 |
| 调控 | (524,108) | 不用 |
| **详情** | (588,108) | **参数全集** |
| 日志 | (652,108) | 不用 |
| 保障历史 | (716,108) | 不用 |

**tab 一律用 JS click，不要用 clickAt**（clickAt 容易打穿到抽屉外，把抽屉关掉）：

```js
(()=>{const t=[...document.querySelectorAll('[class*=tabs-tab]')]
  .filter(e=>{const r=e.getBoundingClientRect();return r.y>60&&r.y<140&&r.x>240&&e.innerText.trim()==='<tab名>'});
if(!t.length)return 'NOTAB';t[t.length-1].click();return 'OK'})()
```

> `[class*=tabs-tab]` 会同时匹配到左侧菜单的「直播/商品/商品视图/计划视图」，所以必须用 y 60–140、x>240 过滤。

### B3 读参数（详情 tab）

```js
(()=>{const t=document.body.innerText;const i=t.indexOf('当前选择的抖音号');
return t.slice(i, i+1400)})()
```

从这里能读到：营销目标、广告类型、优化目标、出价方式、营销服务、ROI 目标、每日预算、投放日期、智能优惠券、新增抖音号自动投、自选投放素材、智能优选素材、AIGC 动态创意。

### B4 读商品

商品 tab 打开后等 3 秒：

```js
[...document.body.innerText.matchAll(/ID[：:]\s*([A-Za-z0-9_]+)/g)].map(m=>m[1])
```

### B5 读抖音号（**等 9 秒**）

```js
(()=>{const t=document.body.innerText;const i=t.indexOf('在投商品信息');
return t.slice(i, i+2000)})()
```

- 抖音号 tab 每页 10 条，**有分页**；翻页用页码元素 JS click
- 抖音号 ID 可能是纯数字（57291868698）也可能是字母数字（CC114580、Koimiao7792、ohh12131415）
- 会出现一条 **「无抖音号（仅含商城流量）」**——计划自带项，创编时**不用选**

### B6 读素材数

```js
(document.body.innerText.replace(/\s+/g,' ').match(/共\s*(\d+)\s*个视频/)||[])[1]
```

素材 tab 默认筛选「投放状态：投放中」，这个数字**通常小于主页实际可选视频数**（历史素材不在其中）。

### B7 参数存档

每次都要落一份 Markdown 到 `F:\AI办公\qc\docs\`，命名 `NN-计划参数-<计划ID>.md`，字段：计划名/ID/状态/ROI/预算/商品ID/抖音号全表/素材数/其余开关。

## 5. 阶段 C：删除（**唯一必须用户确认的步骤**）

### C1 发确认材料（硬规则）

1. 搜索确认「共1条计划」后，**滚动到该行可见**，截图保存
2. 截图必须是**搜索后只剩单条计划的列表页**，能看清：计划名、ID、每日预算、ROI、投放状态
3. **不要发「确定要删除计划吗」的弹窗截图**（用户明确要求）
4. 附上参数表，等用户回「确认删除」

### C2 执行删除

在同一搜索结果页直接点行内「删除」（**JS click 叶子节点**，CDP 坐标点容易点到"编辑"或空白）：

```js
(()=>{const tr=[...document.querySelectorAll('tr')].find(r=>r.innerText.includes('<计划ID>'));
const b=[...tr.querySelectorAll('*')].filter(e=>e.innerText&&e.innerText.trim()==='删除'&&e.children.length===0);
if(!b.length)return 'NOBTN';b[b.length-1].click();return 'OK'})()
```

弹窗文案：「确定要删除计划吗？删除后不可恢复，请谨慎操作。」→ 点「确定」：

```js
(()=>{const btns=[...document.querySelectorAll('button')].filter(b=>b.innerText.trim()==='确定'&&b.getBoundingClientRect().width>0);
if(!btns.length)return 'NOBTN';btns[btns.length-1].click();return 'OK'})()
```

### C3 校验

- 等 8 秒
- 搜索框里该 ID 再搜 → 「共0条计划」
- 或列表总数减 1

> 删除成功后列表区域会被「乘方拿量建议」卡片占满、`tr` 数为 0，属正常；`scroll` 或重新搜索即可。

## 6. 阶段 D：新建计划

### D1 打开新建页

```
https://qianchuan.jinritemai.com/create-ad/overall-product?aavid=1860422794525708
```

（点「+ 商品乘方」按钮有时点空，用 nav 更稳。）**等 13–14 秒**，页面先白屏。
若弹出「联盟合作达人自动投功能上线啦」引导，关掉。

### D2 第 1 步：添加商品

1. 点「添加商品」按钮：
```js
(()=>{const b=[...document.querySelectorAll('button')].find(e=>e.innerText.trim()==='添加商品');if(!b)return 'NOBTN';b.click();return 'OK'})()
```
2. 抽屉里搜商品 ID：`input[placeholder*="商品名称"]` → prototype setter 设值 → `key Enter` → 等 4s，应显示「共1条记录」
3. 勾选该商品行：
```js
(()=>{const id='<商品ID>';
const cands=[...document.querySelectorAll('*')].filter(e=>e.innerText&&e.innerText.includes(id)&&e.querySelector('input[type=checkbox]'));
cands.sort((a,b)=>a.innerText.length-b.innerText.length);
if(!cands.length)return 'NOCB';cands[0].querySelector('input[type=checkbox]').click();return 'OK'})()
```
4. 底部应显示「已选 1/30」（首次读取可能显示 0，再读一次）
5. `clickText "下一步" exact` → 显示「已添加：1/30」，行内出现「添加抖音号」

### D3 第 2 步：添加抖音号

1. `clickText "添加抖音号" exact` → 抽屉「为商品添加抖音号」，全店约 480 条
2. 批量勾选（**每个 ID 单独跑一次脚本，串行最稳**）：
```bash
cd /f/AI办公/qc
node gen-batch11.mjs "抖音号ID1,抖音号ID2,..." batch.json
node cdp.mjs batch.json
```
`gen-batch11.mjs` 的可靠六步：
1. `eval`：`i.focus()` → prototype value setter 清空 → `dispatchEvent(new Event('input',{bubbles:true}))`
2. **绝对不要 `clickAt` 输入框**（会让 `activeElement` 变 body，之后 Enter 全失效；坐标偏了还会点到表格行，把已勾选的号取消掉）
3. `insertText` 输入 ID（必须在 focus 之后）
4. 再 `eval` focus 并断言 `document.activeElement === i`
5. `key Enter`
6. 轮询 8 次 × 2.5s（列表要 5–10 秒才刷新，刷新前一直显示**上一次**的搜索结果）
7. 目标行出现后 `tr.querySelector('input[type=checkbox]').click()`

3. **进度只看底部「当前商品已选：N/30」**，不要看行内 checkbox 的 checked 值（可能显示错误）
4. 全部勾完 → `clickText "确定" exact` 关闭抽屉 → 商品行显示「N个抖音号」

> **冲突提示**：若某行为下方出现「**商品与该抖音号已存在商品投放计划**」，说明该组合仍被别的计划占用，勾选后计数不增加、也加不进去。这时**不要反复尝试**，记下来告诉用户是哪个号、什么提示。
>
> **已删除的抖音号**：详情里抖音号 tab 的记录数可能多于列表行的「N 抖音号」，多出来的是原计划中已删除的号；它们在抽屉里勾不上（计数不增），**也不需要加**。最终计数与列表行显示的 N 一致即可。

### D4 第 3–6 步：表单

| 项 | 定位 | 填法 |
|---|---|---|
| 综合营销ROI目标 | `input.aurora-qc-input-number-input`（页面里有 2 个，**取第 1 个**） | 先 `scrollIntoView({block:'center'})` + `.click()` + `.focus()`，再 `setInput` |
| 每日预算 | `input[placeholder="请输入"]` | `setInput` |
| 计划名称 | `input[placeholder*="计划名称"]` | `setInput` |
| 投放日期 | 默认「从今天起长期投放」 | 不动 |
| 智能优惠券 | `button[role=switch]` | 默认 `aria-checked=true`，不动 |
| AIGC 动态创意 | `button[role=switch]`（第 2 个） | 默认 false，不动 |
| 含达人佣金出价 | 达人营销卡片里的 checkbox | **系统会自动勾上**（toast「已默认开启含达人佣金出价」），核对为 true 即可 |
| 新增抖音号自动投 | 开关 | 保持关闭 |

计划名规则：**原计划名 + 把日期后缀换成当天**，例如
`水乳2.0&橙子--11月--1组-1--1113` → `水乳2.0&橙子--11月--1组-1-1116`（限 50 字符）。

核对三个值（ROI/预算/计划名）是否写进去了：

```js
(()=>{const roi=document.querySelector('input.aurora-qc-input-number-input')?.value;

const name=document.querySelector('input[placeholder*="计划名称"]')?.value;

```

### D5 发布

1. 「发布计划」按钮在视口外时 `clickText` 会点在页面外，**先滚到可见再点**：
```js
(()=>{const b=[...document.querySelectorAll('button')].find(e=>e.innerText.trim()==='发布计划');
if(!b)return 'NOBTN';b.scrollIntoView({block:'center'});const r=b.getBoundingClientRect();
return {x:Math.round(r.x+r.width/2),y:Math.round(r.y+r.height/2)}})()
```
→ `clickAt` 得到的坐标
2. 弹窗「为保证乘方投放的唯一性…互斥的全域投放计划将被删除；小店随心推订单将被终止」→ `clickText "确认发布" exact`
3. 页面跳回 `overall-prom`（URL 含 `sourceFrom=createSuccess`）
4. 读新计划 ID：点「商品自选」→ 用**计划名**搜索 → 「共1条」→ 行内 `ID：xxx`

> 若点「发布计划」后没弹唯一性弹窗，多半是抖音号抽屉还开着挡住了按钮（z-index 覆盖），先点抽屉「确定」关掉再点发布。

## 7. 阶段 E：素材（逐号全选抖音主页素材）

### E1 打开添加视频弹窗

1. 点计划名打开抽屉（URL 出现 adId）
2. 素材 tab：JS click（同 B2 的写法）
3. `clickText "添加视频" exact` → 弹窗打开
4. 判定：页面文本含 `/已选择 \d+\/200/`

弹窗结构：
- 顶部 tab：我的视频 / 上传视频 / 其他视频
- 抖音号横向列表：`.main-vmok-plugin-tabs__nav-list`（页面里有两个同名容器，**抖音号列表是元素多的那个**，最后一项是滚动条占位 `.main-vmok-plugin-tabs__bar` 要跳过）
- 素材卡片：`.main-vmok-plugin-create-material-list-card-item`，itemid 在子元素 `c.querySelector('[itemid]').getAttribute('itemid')`
- 底部：「已选择 N/200」是**当前抖音号**本次选中的数量，不是总数

### E2 批量全选

```bash
cd /f/AI办公/qc && node pick-all.mjs "抖音号名1,抖音号名2,...,抖音号名N"
```

- **必须传逗号分隔的名字串**；只有一个号时也要写成 `"名字,"`（带尾逗号），否则脚本会去读 out 目录报「没有抖音号名单」
- 名字按弹窗里 tab 的实际文字写，**带 emoji 和全角括号的要原样写并加引号**
- 脚本行为：逐号 JS click 切 tab → 等 2.6s → 按 itemid 找卡片 → **真实鼠标点击**全部卡片 → 最后点「确定」提交
- 输出 `{"ok":true,"submitted":true,"totalVideos":"共N个视频","log":[{name,cards,before,after,delta}]}`

关键机制：
- 切号必须 **JS `.click()`**（横向列表 `scrollIntoView` 完全无效，x 会变负数）
- 卡片必须 **真实 CDP 鼠标点击**（JS click / 合成 PointerEvent 都不生效）
- **已添加过的视频仍显示在列表里，只是点了没反应** → 补选时对全部卡片点一遍即可
- 不要点「查看全部已选」：关那个小窗时会把整个添加弹窗一起关掉，本次选择全丢

### E3 核对

```js
(document.body.innerText.replace(/\s+/g,' ').match(/共\s*(\d+)\s*个视频/)||[])[1]
```

等于各抖音号主页视频数之和即通过。若明显少于预期，重新打开「添加视频」补选一遍。

## 9. 故障排查速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 列表「共0条计划」且无行 | 落在全店托管 / 未加载完 | 点「商品自选」radio，等 4s |
| 搜索结果不是 1 条 | ID 输入没生效 | 重设输入框 → 真实 Enter，等 5s |
| 点击计划名无反应 | 行不在视口内 | 先 `scrollIntoView({block:'center'})` 再取坐标 |
| 抽屉空白/加载中 | 抽屉渲染失败 | nav 回列表，重新搜索，再点计划名 |
| 发布按钮点了没反应 | 被抽屉挡住 / 在视口外 | 先关抽屉，再 `scrollIntoView` 后 clickAt |
| 抖音号勾不上、计数不增 | 已被其他计划占用 / 是已删除的号 | 记录并上报，别硬试 |
| 素材卡片点了没选中 | 用的是 JS click | 改真实鼠标点击（pick-all.mjs 已处理） |
| 全选后视频数偏少 | 某号切 tab 失败 | 看脚本 log 里哪号 cards=0，重跑该号 |
