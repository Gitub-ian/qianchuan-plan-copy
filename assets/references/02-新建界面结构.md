# 新建商品乘方 · 界面结构与参数

记录时间：2026-11-14
依据：用户 m00402 口述规则 + 浏览器实测（账户 1860422794525708）

## 一、入口

- 新建页：`https://qianchuan.jinritemai.com/create-ad/overall-product?aavid=1860422794525708&type=create`
- 编辑已有计划：同 URL 加 `&adId=<计划ID>&type=edit`
- 左侧 6 步导航固定：选择投放对象 / 素材创意 / 达人营销 / 营销目标与预算 / 增值权益 / 计划名称
- 底部右侧：`发布计划`（蓝）、`取消`

## 二、六步参数（创建时到底填什么）

### 1. 选择投放对象

| 项 | 说明 |
|---|---|
| 投放商品 | 必填，1~30 个。点「添加商品」开右侧抽屉 |
| 投放抖音号 | 每个商品单独选，1~30 个。行内点「添加抖音号」开抽屉 |
| 素材 | 可先不填（默认启用智能优选素材） |

商品抽屉：tab「全部 / 店铺新品 / 破圈尖货 / 搜索趋势」；搜索框 `input.ovui-input[placeholder="请输入商品名称/ID搜索"]`；表格列 商品信息 / 标签 / 类目 / 销量 / 库存 / 带货达人数 / 首次上架时间；底部「已选 x/30」+ 取消 / 下一步。

抖音号抽屉（标题「为商品添加抖音号」）：
- 顶部「联盟合作达人自动投」开关（默认关，创建时不碰）+ 推荐开启横幅
- 手动选择抖音号：搜索框 `input[placeholder="请输入抖音号名称或ID搜索"]`、授权类型、授权状态、只看可投抖音号
- 表格列：抖音号（头像 / 名称 / ID）/ 授权类型（合作达人 / 联盟合作）/ 带货佣金率 / 授权状态 / 渠道品
- 全店共 475 条，10 条/页，可按抖音号 ID 精确搜到

**勾选方式（实测）**：表格行复选框是 `input.ovui-checkbox__input`，**CDP 坐标点击无效**，必须用 JS `input.click()` 才会被 React 接住。

### 2. 素材创意

| 项 | 规则 |
|---|---|
| 智能优选素材 | **必选**，系统强制，无开关，不动 |
| AIGC 动态创意 | 非自营账号无法开启，不动 |
| 自选素材 | 可空（0 条自选素材 0 条标题） |

### 3. 达人营销（三张卡）

| 卡片 | 控件 | 创建时 |
|---|---|---|
| ① 双佣金 · 扩合作 | 「去设置」链接 | 不管 |
| ② 联盟合作达人自动投 · 提效率 | 卡内 checkbox，默认未勾 | 不管 |
| ③ 含达人佣金出价 · 拿增量 | 卡内 checkbox，默认未勾 | **需要勾选** |

### 4. 营销目标与预算

| 项 | 说明 |
|---|---|
| 综合营销ROI目标 | 输入框（`aurora-qc-input-number-input`），公式 = 净成交金额 ÷ 整体消耗；按原计划值填 |
| 出价分析 | 建议出价（如 2.23）、历史综合ROI（如 1.72）、达标率 77.1%、「采纳建议」按钮；仅供参考 |
| 投放日预算 | 数字输入框 + 单位「元」，按原计划值填 |
| 投放日期 | 默认「从今日起长期投放」；另一选项「设置开始和结束日期」 |

### 5. 增值权益

| 项 | 说明 |
|---|---|
| 智能优惠券 | `button.aurora-qc-switch[role=switch]`，**默认已启用（aria-checked=true）**；创建时需开启 |
| 智能升额权益 | 同区第二项，按需 |

### 6. 计划名称

- 输入框 `input[placeholder="请输入计划名称，1-50个字符"]`，限 50 字
- 系统默认值格式：`2026-11-14_千川乘方_23:11:55`（日期_千川乘方_时间）
- **复制规则：填原计划名称，只把日期后缀改成当日**

## 三、唯一性规则（复制的根因）

乘方计划以「商品 × 抖音号」唯一：同一商品 + 同一抖音号在全店只能存在一条计划。
不同组合互不影响（商品A×抖音B 与 商品A×抖音C 可并存）。

实测证据：给商品 3753172852644381108 选抖音号 57291868698 时，表格下方出现「**商品与该抖音号已存在商品**」，勾选无效，确定后被弹回「请为该商品选择要投放的抖音号」。

因此"复制计划"只能走：**读参数 → 删原计划 → 用同一组商品/抖音号重建**。

## 四、控件定位速查（1528×732 视口，逻辑坐标）

| 元素 | 定位方式 |
|---|---|
| 商品搜索框 | `input.ovui-input[placeholder*="商品名称"]` |
| 抖音号搜索框 | `input[placeholder*="抖音号名称"]` |
| 表格行复选框 | `input.ovui-checkbox__input`，JS `.click()` |
| 计划名输入框 | `input[placeholder*="计划名称"]` |
| 各类开关 | `button.aurora-qc-switch[role=switch]` 的 `aria-checked` |
| 抽屉底部「下一步 / 确定」 | 坐标约 (1454, 695) |
| 抽屉底部「取消」 | 坐标约 (1454, 695) 左侧约 120px |
| 引导气泡「跳过 / 下一步」 | shadow DOM（FIREFLY-REACT-CONTENT）内取 rect 中心后 clickAt |

## 五、复制计划标准动作（草案，待首个计划 ID 实操验证）

1. 列表页按计划 ID 搜索 → 打开详情抽屉（URL 加 `&adId=`）→ 记录：计划名、商品ID、抖音号ID（全部，注意分页）、ROI、日预算、投放日期、达人佣金出价、智能优惠券等
2. 截图给用户确认
3. 用户确认后删除原计划（列表行「删除」）
4. 新建页按记录填：商品（搜ID→勾选→下一步）→ 抖音号（搜ID→勾选→确定，每个商品重复）→ 含达人佣金出价勾上 → ROI / 日预算 / 投放日期 → 智能优惠券开启 → 计划名（改日期后缀）
5. 发布前截图确认 → 发布
