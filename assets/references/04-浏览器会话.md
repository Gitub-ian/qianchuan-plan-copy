- req.json 格式：`{"actions":[{"cmd":"eval","expr":"..."},{"cmd":"shot","path":"..."}]}`
- 可用 cmd：eval / shot / click / clickAt / clickText / setInput / insertText / keys / nav / wait / scroll / reload / text / inputs / frames / tabs

## 三、已知坑（都踩过）

1. **截图挂起**：`Page.captureScreenshot` 在窗口非前台时会一直不返回 → 已改成先 `Page.bringToFront` + `fromSurface:false`。
2. **引导气泡在 shadow DOM**：`<FIREFLY-REACT-CONTENT>`，querySelector 找不到「跳过」，需递归 shadowRoot 取坐标后 clickAt。
3. **坐标点击对表格复选框无效**：`input.ovui-checkbox__input` 必须 JS `.click()`。
4. **cmd 脚本不能写中文注释**：UTF-8 文件被 cmd 按 GBK 读，注释会把下一行吃掉（`setlocal` 变 `tlocal`）。启动器已全英文。
5. **`(x86)` 在 cmd 的 start 参数里会被当子命令**：启动器改成 `pushd` 到 Edge 目录后 `start "" msedge.exe`，路径不出现在参数里。
