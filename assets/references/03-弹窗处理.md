# 弹窗 / 气泡 / 提示 处理规则

记录时间：2026-11-14（用户 m00270 指示：这类东西会经常弹，一般与创建计划无关，直接关闭）

## 总规则

1. **默认关闭**，不读内容、不点「下一步」、不点任何引导里的主按钮（会改变页面状态或触发新一轮引导）。
2. 关闭优先顺序：`跳过` > `×` > `我知道了` > 空白处。
3. 关闭后再继续原动作；如果原动作没生效，重做一次。
4. 不要点右下角「智投星」悬浮球（常驻客服入口，点了会开新面板）。
5. 唯一例外：**业务提示**要看（如"商品与该抖音号已存在商品""部分商品未选择抖音号"），它决定下一步怎么做。

## 已见类型

### A. 新手引导气泡（蓝色，带 跳过 / 下一步）

- 出现位置：新建页首次进入、「添加商品」按钮旁、右侧广告位
- 实现：Web Component `<FIREFLY-REACT-CONTENT>`，内容在 **shadow DOM** 里，普通 `querySelector` 找不到「跳过」
- 遮罩会拦截点击，导致按钮点了没反应（表现为"点添加商品没打开弹窗"）
- 处理：递归遍历 shadowRoot 找到文本为「跳过」的元素 → 取 `getBoundingClientRect()` 中心 → `clickAt(x,y)`
- 实测坐标示例：跳过 ≈ (452,400)、下一步 ≈ (514,400)

### B. 营销弹窗（右侧大图，如「联盟合作达人自动投功能上线啦」）

- 右上角 `×`，坐标点击即可
- 实测关闭坐标 ≈ (1310,53)

### C. 顶部提示条（蓝底，如「投放账户内可为不同商品新建多条计划，建议相似商品集中在一条计划下投放」）

- 右侧 `×` 关闭；不关闭也不挡操作，可忽略

### D. 二次确认弹窗（白底，如「部分商品未选择抖音号，确定提交吗？」）

- 两个按钮：`再想想` / `确定`
- 出现原因：抽屉里勾了商品但没勾抖音号就点确定
- 处理：点「再想想」→ 回到抽屉补选，不要硬点确定（硬点也加不进去）

### E. 行内业务提示（表格下方红/灰字）

- 「商品与该抖音号已存在商品」→ 该组合已被其他计划占用，必须先删原计划
- 这类提示不关闭，它是指令性信息

### F. 抽屉（添加商品 / 为商品添加抖音号）

- 不是弹窗，是右侧抽屉，用「取消 / 下一步 / 确定」控制
- 关闭：点左上 `×`（截图坐标 ≈ (502,29)）或底部「取消」

## 判断流程

```
出现浮层
 ├─ 有「跳过」            → 点跳过
 ├─ 有「×」               → 点 ×
 ├─ 是「再想想/确定」二次确认 → 点再想想，回去补齐
 ├─ 是业务提示（红字/行内） → 读它，按它调整
 └─ 是抽屉              → 按底部按钮操作
```
